# Gov Document Fetcher

Τοπική εφαρμογή που κατεβάζει αυτόματα φορολογικά έγγραφα από τα portals της
ΑΑΔΕ (TaxisNet), με σωστή ονομασία αρχείων.

| Τύπος πελάτη | Έγγραφα |
|---|---|
| Ατομική επιχείρηση | Ε1, Ε3, Εκκαθαριστικό, ΦΠΑ |
| Νομικό πρόσωπο (ΟΕ, ΕΕ, ΑΕ…) | Ν, Ε3, ΦΠΑ |

Κατεβαίνει ό,τι υπάρχει κάθε φορά: αν ένα έγγραφο δεν υπάρχει για τον
συγκεκριμένο πελάτη ή έτος, σημειώνεται και η διαδικασία συνεχίζει.

## Προϋποθέσεις

**Python 3.9 ή νεότερη.** Τίποτα άλλο — ο Chromium κατεβαίνει αυτόματα την
πρώτη φορά (~150 MB).

- **macOS**: υπάρχει ήδη. Έλεγχος: `python3 --version`
- **Windows**: κατέβασέ την από [python.org](https://www.python.org/downloads/)
  και στην εγκατάσταση τσέκαρε **«Add python.exe to PATH»**.
  Έλεγχος: `python --version`

## Εγκατάσταση και εκκίνηση

```bash
git clone git@github.com:chatzilefterislef/gov-doc-fetcher.git
cd gov-doc-fetcher
```

Μετά, μία εντολή — φτιάχνει το περιβάλλον, εγκαθιστά ό,τι χρειάζεται και ανοίγει
την εφαρμογή:

**macOS / Linux**

```bash
python3 run.py
```

**Windows**

```bash
python run.py
```

Η πρώτη εκτέλεση παίρνει ένα-δύο λεπτά (κατεβαίνει ο Chromium). Οι επόμενες
είναι άμεσες. Η εφαρμογή ανοίγει στο <http://localhost:8000>.

Αν η πόρτα 8000 είναι πιασμένη: `python3 run.py --port 8001`

## Χρήση

1. Κωδικοί TaxisNet του πελάτη
2. Ονοματεπώνυμο ή επωνυμία — μπαίνει στο όνομα του αρχείου
3. Χρονολογία
4. Διακόπτης **Ατομική Επιχείρηση** — καθορίζει ποια έγγραφα ζητούνται
5. **Έναρξη Λήψης**

Θα ανοίξει ένα παράθυρο Chromium που κάνει την πλοήγηση μόνο του· άφησέ το να
δουλέψει. Η πρόοδος φαίνεται ζωντανά στην εφαρμογή και στο τέλος βγαίνει σύνοψη:
τι κατέβηκε, τι δεν υπήρχε, τι απέτυχε.

Τα PDF αποθηκεύονται στο `~/Downloads/GovDocs` (στα Windows:
`C:\Users\<όνομα>\Downloads\GovDocs`).

## Μέσα από Claude Code

Το repo έχει έτοιμο preview config. Άνοιξε τον φάκελο με Claude Code και ζήτα
«ξεκίνα την εφαρμογή» — θα χρησιμοποιήσει το `.claude/launch.json`. Υπάρχουν δύο
configurations, `gov-doc-fetcher` για macOS/Linux και `gov-doc-fetcher (windows)`.

Το [CLAUDE.md](CLAUDE.md) περιέχει τη δομή του κώδικα και τις παγίδες των portals
της ΑΑΔΕ, ώστε ο Claude να μη ξανακάνει λάθη που έχουν κοστίσει χρόνο.

## Όταν κάτι χαλάει

Κάθε τρέξιμο γράφει αναλυτικό log με τα βήματα, τα URL και τα κουμπιά που
βρέθηκε σε κάθε σελίδα:

```bash
cat /tmp/gov_doc_fetcher.log
```

Στα Windows είναι στον προσωρινό φάκελο — δες τη διαδρομή που τυπώνει η
εφαρμογή. Δίπλα υπάρχουν screenshots `gov_debug_*.png` από τα σημεία που
απέτυχαν. Στείλε αυτά τα δύο και το πρόβλημα εντοπίζεται γρήγορα.

Τα portals της ΑΑΔΕ αλλάζουν κάθε τόσο, οπότε κάποιο βήμα μπορεί να χρειαστεί
προσαρμογή· το log δείχνει ακριβώς πού.

## Ασφάλεια

Όλα τρέχουν τοπικά στον υπολογιστή σου. Οι κωδικοί TaxisNet χρησιμοποιούνται
μόνο για το login και **δεν αποθηκεύονται** — ούτε σε αρχείο, ούτε στο log.

Τα κατεβασμένα PDF είναι φορολογικά στοιχεία πελατών. Το `.gitignore` αποκλείει
τα `*.pdf`, ώστε να μη ανέβουν ποτέ κατά λάθος στο repository.
